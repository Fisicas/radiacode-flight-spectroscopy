# Included and planned outputs

“Included” means intended for the public v0.1 snapshot. Pressure/depth products,
route/altitude figures, and animations derived from FlightAware website data
are included for noncommercial academic review but excluded from the
repository's MIT and CC BY 4.0 licenses; see
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

| Product | v0.1 status | Role |
|---|---|---|
| Four detector `.rcspg` inputs | Included with hashes | Original detector evidence |
| FlightAware KML tracks | Not distributed; retrieval identifiers and hashes included | Local route/altitude context |
| Pressure/depth summary tables | Included under `data/derived/` | Inspectable four-flight numeric result |
| ATL → OMA model, predictions, and JSON | Included and reproducible | Count-level case study |
| Calibration XML, anchors, and converted CSVs | Included and deterministic-checkable | Working channel-to-energy evidence |
| Centroid uncertainties, held-out folds, and feature diagnostics | Included and deterministic-checkable | Precision limits for the working calibration |
| Figures 01–05 PNG/SVG | Included | Publication and scalable presentation products |
| Figure 06 PNG | Included and reproducible | Poisson-model visualization |
| Featured GIF and static panel fallbacks | Included | GitHub-readable visual overview |
| Full-resolution dashboard/panel GIFs | Optional GitHub Release assets | Detailed synchronized media |
| Native UTC-merged tables | Planned for v0.2 | Portable time-aligned detector/track output |
| Full pressure-resolved spectra and run metadata | Planned for v0.2 | Clean-clone regeneration record |

CSV and JSON products are the authoritative derived record. Figures and
animations are explanatory products and should be interpreted through their
captions, methods, and stated limitations.

Figure 01 is publication-facing and reproducible from
`scripts/build_figure_01.py`; `--check` verifies that its SVG master and PNG
rendering remain synchronized. It is conceptual and not to scale. Figures
02–05 belong to the v0.1 result snapshot; Figure 06 is regenerated by the
committed single-flight analysis script.
