# Command-line workflow

## Install and validate the synthetic fixture

```powershell
python -m pip install -e .
radiacode-flight validate --manifest config/example_manifest.csv
```

The synthetic pair exercises detector parsing, KML parsing, UTC overlap, and
the expected small-fixture channel-count warning.

## Validate the public detector snapshot

```powershell
radiacode-flight validate --manifest config/four_flights.csv
```

The validator checks manifest structure, detector file existence, SHA-256,
JSON structure, positive live time, timestamp order and duplicates, pulse-array
length, and channel count. It emits one expected warning per row because the
FlightAware KML is intentionally not distributed.

## Validate a local detector/track pair

Retrieve a permitted KML as described in [`../data/README.md`](../data/README.md)
and store it outside the public tree or under ignored `data/private/`. Create an
ignored local manifest by copying the public detector manifest, then add the
local `track_file` paths and, when available, their SHA-256 values:

```powershell
Copy-Item config/four_flights.csv config/current_four_flights.local.csv
radiacode-flight validate --manifest config/current_four_flights.local.csv
```

When `track_file` is populated, validation also checks paired KML timestamps and
coordinates, ordering and duplicates, optional SHA-256, and UTC overlap with the
detector record.

## Reproduce the focused analyses

The pooled descriptive fit uses the compact four-flight tables:

```powershell
python scripts/analyze_overflow_pressure.py
```

The ATL → OMA count-level analysis regenerates Figure 06, the model table,
prediction table, and JSON summary:

```powershell
python scripts/analyze_featured_flight_overflow.py
```

Figure 01 is independently reproducible from vector primitives:

```powershell
python scripts/build_figure_01.py
python scripts/build_figure_01.py --check
```

The check regenerates the SVG in a temporary directory and verifies that the
committed SVG master and PNG rendering are a synchronized pair.

Verify deterministic calibration exports and run tests:

```powershell
python calibration/recalibrate_spectra.py --check
python calibration/validate_peak_centroids.py --check
python scripts/build_figure_01.py --check
python -m unittest discover -s tests -v
```

## Snapshot boundary

Figures 02–05 and the animations were generated by the original local analysis
environment from detector/KML pairs and normalized intermediate products. The
complete merge, normalization, multi-figure, and animation path is not yet
runnable from a clean clone. The committed CSV/JSON outputs and figures are a
reviewable result snapshot; the [public roadmap](migration_plan.md) describes
the portability work planned for v0.2.

Because the route-derived coordinates came from FlightAware website data,
those derived tables, figures, and animations are excluded from the project
MIT and CC BY 4.0 licenses. They are included for noncommercial academic review
under the rights notice in
