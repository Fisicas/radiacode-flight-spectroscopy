# Presentation figures

The PNG files are optimized for display in the repository README. SVG files
are the scalable masters where available. Figure 01's displayed PNG is linked
to its SVG from the landing page.

| Figure | Status and interpretation |
|---|---|
| Figure 01 — physics cascade to detector | Publication-facing conceptual schematic; generated by `scripts/build_figure_01.py`; not to scale. |
| Figure 02 — atmospheric depth and pressure | ISA-equivalent pressure calculated from track-reported altitude; source altitude type is unverified. |
| Figure 03 — analysis workflow | Workflow used for this release, including the boundary between committed and local-only steps. |
| Figure 04 — four-flight comparison | Detector observables shown over the locally analyzed external-track overlap. |
| Figure 05 — pressure-binned response | Flight-balanced detector response; terminal-channel energy is a calibration extrapolation. |
| Figure 06 — ATL → OMA case study | Count-level Poisson analysis regenerated by `scripts/analyze_featured_flight_overflow.py`. |

Regenerate and verify Figure 01 from the repository root:

```powershell
python scripts/build_figure_01.py
python scripts/build_figure_01.py --check
```

Figure 01 records detector pulse height reported as γ-calibrated visible
energy. It does not identify particle species or directly measure incident
cosmic-ray flux. See the landing-page caption for its clickable references and
scope caveats.
